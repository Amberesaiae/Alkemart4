## Release fixes

- Narrowed the handover-code generator's random-buffer type to its actual
  `ArrayBuffer` backing store, fixing production TypeScript builds without
  changing its rejection-sampling behavior.
- Root API/domain test commands now use each package's installed Vitest
  rather than letting `bunx` resolve a different release from the root.
- Deployment instructions now describe the real migration runner, complete
  history check, session-pooler fallback, and schema-plus-data backups.
- Browser verification found the retired storefront's Workbox worker still
  serving its cached v1 HTML after Pages had deployed v2. The v2 app now
  publishes a retirement worker at the original `/sw.js` URL. It activates
  immediately, clears only the known legacy caches, claims existing clients,
  and unregisters itself. It does not intercept requests or reload forms.
  `/sw.js` is served with `Cache-Control: no-store`.
