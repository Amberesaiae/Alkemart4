# Empty-state family — v2

Created with the built-in image-generation tool. Subtle tone-on-tone brand marks integrated into objects replace the standalone companion. Transparent PNGs, retained alongside v1; not yet wired to screens.

## Prompt set

### empty-cart

Use case: illustration-story. Create one refined Alkemart ecommerce empty-state spot illustration on a genuinely transparent background. Square composition with generous margins, one compact central scene, no text, no watermarks, no UI. Consistent family style: rounded charcoal outlines #1d1d24, restrained gold #FEBF31 and ivory fills, simple flat editorial drawing with very subtle material shading. No standalone mascot, no floating logo, no multicolored spark next to the object. Input image is ONLY a reference for the shape of a tiny tone-on-tone engraved five-part brand mark: one circle and four tapered petals. That mark must be a subtle physical detail on the object, under 5% of the main object's width, low contrast in the object's own material color. The objects and calm composition are the focus. Subject: A single open empty gold paper shopping bag, soft charcoal handles, three-quarter view, visibly empty ivory interior. Tiny debossed gold-on-gold brand stamp near the lower side corner of the bag, integrated into its material.
